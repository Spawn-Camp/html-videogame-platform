## ✨ Características

- **Carrusel dinámico** - navegación fluida estilo consola moderna
- **Fondo reactivo** - el color cambia según el juego seleccionado
- **Sonido inmersivo** - efectos de audio sintetizados (Web Audio API), sin archivos externos
- **Navegación híbrida** - teclado, click, arrastre y touch
- **Animación de inicio** - splash screen al cargar
- **Diseño oscuro neón** - estética gaming profesional
- **100% un solo archivo** - todo el CSS y JS unificado en `index.html`

## 🚀 Cómo usar

1. Clona el repositorio
```bash
git clone https://github.com/Jeuri-Ddz/SpawnCamp.git
```

2. Abre `index.html` en tu navegador — no requiere servidor ni dependencias.

---

## 🕹️ Controles

| Acción | Método |
|--------|--------|
| Navegar | `← →` teclado · flechas laterales · click en tarjeta |
| Deslizar | Click + arrastrar · swipe táctil |
| Jugar | `Enter` · doble click |

---

## 🛠️ Tecnologías

- HTML5 + CSS3 + JavaScript vanilla
- Web Audio API (sonidos sintetizados)
- Canvas API (partículas animadas)
- Google Fonts — Orbitron + Rajdhani
- Sin frameworks · Sin dependencias · Sin archivos externos
